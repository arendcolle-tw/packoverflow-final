# Check before you say done

1. Run the app or the changed script.
2. Walk the main path once, the way a judge would, and note anything that breaks.
3. Capture a screenshot, or the command output if there is no screen.
4. Commit and push to your branch.
5. Report in five lines or fewer: what works, what you saw, the branch, and the screenshot.

If you cannot run it, say so in the first line. Do not report it as done.
